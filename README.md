# Битва групп: эмо · скримо · металкор

Тест в стиле picu.co: из двух групп выбираешь одну, пока не останется лучшая. В каждой карточке — лучший трек группы (клип или трек с YouTube). В конце — таблица топа.

Фильтры: русские и СНГ / зарубежные, известные / андеграунд, жанры (эмо, скримо, пост-хардкор, металкор, дэткор, маткор, поп-панк, альтернатива).

- `data/*.txt` — список групп. Строка: `Группа | Трек | страна | жанр | *` (трек можно оставить пустым — тогда возьмётся самый популярный клип; `*` = андеграунд).
- `scripts/build_bands.py` — собирает `data/*.txt` в `site/bands.json` (повторы убирает).
- `scripts/fetch_videos.py` — ищет ролики на YouTube (yt-dlp), проверяет, что в ролике та самая группа и его можно встроить.
- `.github/workflows/pages.yml` — при каждом пуше ищет недостающие ролики и публикует сайт.

Добавить группу: допиши строку в любой `data/*.txt` и запушь — ролик найдётся сам.
Ролик не тот: удали группу из `site/videos.json` и укажи трек в `data/*.txt`.
