# Musictest — прогресс

**Цель:** тест в стиле picu.co (как Gamestest): из двух групп выбираешь одну, пока не останется лучшая. Эмо / скримо / металкор / пост-хардкор, русские и зарубежные группы, до 2000 групп. В карточке — лучший трек группы (клип или просто трек с YouTube).

**Схема (как в Gamestest):** `site/bands.json` (группа, трек, страна, жанр) → GitHub Actions + yt-dlp ищет ролики → `site/videos.json` → GitHub Pages.
